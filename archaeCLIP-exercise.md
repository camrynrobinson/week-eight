One could use the archaeCLIP visual search engine software to identify different types of dog tags from battlefield sites, like the work that J.L. Gassend explains on his YouTube channel. Identifying tag origins is something that archaeologists already do visually (once you spend enough time looking at them you get used to which shape/style comes from which country) but it could be helpful for processing large numbers of tags (from a mass grave for example) or for identifying patterns in tag condition/appearance/composition: for example, depending on production mechanisms (where/at what scale were tags produced), things like recipe ratios or consistent defects (ie. a reproduced identical dent/mark from a machine), could reveal connections between two individuals previously thought to be unrelated.

- if the information on the tags was legible, a visual database combined with a transcription/conversion program like PaddleOCR would allow for even more refined navigation of the assembly, but i don't know how much success it would have reading embossed text on a dirty metal tag rather than printed documentation.
